# Greek decision explanations

The feed's source, solution category, catalog match, lifecycle stage, solution route, freshness, priority, verdict, confidence and four assessment factors now use Greek-facing labels. Each core decision cue has the same hover-and-keyboard-focus explanation pattern.

The explanations describe the meaning and limits of a signal—for example, a catalog match is a lead to investigate, not proof of compliance, and confidence describes evidence quality rather than win probability. This keeps the decision-first model explainable without adding another dashboard surface.

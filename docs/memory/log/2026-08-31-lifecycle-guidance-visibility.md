# Lifecycle guidance visibility

The details view now renders lifecycle guidance for every loaded opportunity. When the source response omits guidance, the UI shows an explicit unknown-stage fallback with safe next steps instead of leaving a blank gap. The panel header has a stable minimum height and remains the control for expanding or collapsing the detailed tracker.
